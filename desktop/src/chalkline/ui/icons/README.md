# Markup symbols

These SVG paths are copied directly from `TOOLS` in the root PWA `index.html`.
The wrapper matches `renderTools`: 24×24 viewBox, 1.7 stroke, rounded joins/caps.
Qt tints the symbols to the native button colour. Pan uses the PWA's ✋ glyph.
Keep tool IDs as filenames; package data includes these local SVG assets.
